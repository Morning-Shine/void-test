# баг 1: невозможность установки услуги в селекте
Решение: 
* в компонент ProjectBuilder добавлено локальное состояние для управления данными, связано с селектом

# баг 2: не активна кнопка добавления при выборе услуги
Решение: 
* кнопка через общего родителя связывается с инпутом и получает информацию о необходимости "активности", а также актуальную услугу для запуска функции добавления

# баг 3: не происходит добавления услуги
Причина: список услуг записывался в переменную, а не в состояние - таблица не получала актуальные данные
Решение: добавлено состояние для списка услуг, которое обновляется сразу по нажатии кнопки


# баг 4: не актуальное инпуту количество
Причина: данные о количестве услуг записывались в значение переменной вместо того, чтобы использовать стэйт - реакт так не обновляет данные
Решение: добавлен еще один стэйт для актуализации информации по количеству 

# баг 5: не удаляются сервисы
Решение:
* изменение функции удаления (использование функции управления состоянием)
